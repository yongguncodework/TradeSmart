# Global Risk & Journal Rules

## Non-negotiables
- Max daily portfolio loss: **3%** — stop trading for the day if hit.
- Max single position: **15%** of portfolio ( **8%** for leveraged ETFs ).
- Max correlated exposure (BTC + QQQ + SOXL): treat as one tech/risk bucket ≤ 25%.

## Pre-trade checklist
1. Write one-sentence thesis and invalidation level before order entry.
2. Confirm position size from stop distance (risk <= 1% per trade for active sleeve).
3. Check economic calendar for binary events in next 24 hours.
4. Log emotional state 1–5; skip discretionary trades if >= 4 (reactive).

## Post-trade journal (required)
- Setup tag: breakout / pullback / mean-reversion / macro
- Result in R-multiples, not dollars
- One improvement note — no narrative excuses

## Agent usage policy
- Use TradeSmrt for **research briefs**, not as an execution signal.
- If agent risk flags include HIGH severity, default action is **wait or reduce size**.
- Cross-check agent thesis against this playbook file before placing orders.

## Circuit breakers
- Three consecutive losing days: cut size 50% for one week.
- Weekly drawdown > 5%: move to core ETF sleeve only (no SOXL) until recovery.
- Any rule break: mandatory 24h pause from discretionary trading.
